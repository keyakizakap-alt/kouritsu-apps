Power BI データビューア

CSV・Excel をブラウザ内で可視化

Python を準備中…

ローカル完結・インストール不要

Power BI から出したデータを、
その場でグラフに。

エクスポートした CSV / Excel を選ぶだけで、集計・推移・分布・相関・クロス集計を表示します。 解析は Python（pandas）がブラウザ内で実行し、ファイルは外部に送信されません。

  1. 1

    ビジュアルの「…」を開く

    Power BI Desktop / サービスで、出力したい表やグラフの右上「その他のオプション」を選びます。

  2. 2

    「データのエクスポート」

    .xlsx（最大15万行）か .csv（最大3万行）を選んで保存します。上限はビジュアルや管理者設定で小さくなる場合があります。

  3. 3

    このページで開く

    列の型（数値・日付・カテゴリ）を自動判定し、集計しやすい形でグラフ化します。

フィルター

    処理中…

    ファイルはブラウザ内だけで処理されます。初回はライブラリ（Pyodide・pandas・ECharts）を CDN から取得するため、インターネット接続が必要です。
